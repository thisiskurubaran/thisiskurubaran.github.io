# Tide Support

Need help with Tide, found a bug, or have an idea? Email
[thisiskurubaran@gmail.com](mailto:thisiskurubaran@gmail.com). In the app,
**Settings > Help & feedback > Report a problem** writes the email for you
and attaches the details that help me fix things.

## Common questions

**Does Tide cost anything?**
No. Every feature and every extension is free, with no subscription.
Extensions are installed from the Extensions screen. There are no
in-app purchases.

**What runs on the device?**
JavaScript and TypeScript (Node.js), Python, Lua, Ruby and PHP run on the
device, offline. npm and pip install pure-JavaScript and pure-Python
packages. Anything else, such as native builds or other languages, needs
Remote mode with a Tide server you host.

**How do I use the AI features?**
Add your own key for Anthropic, OpenAI, Google Gemini or OpenRouter, or the
address of your own Ollama or LM Studio server, in Settings > AI assistant.
Keys stay in the Keychain and requests go straight to the provider. Any
charges come from your provider, not from Tide.

**Remote mode says my Tide server is out of date. What do I do?**
Tide 2.0.0 needs the latest server. Run `git pull` on the server, then
restart it.

**Where are my files?**
In Tide's own storage on the device, included in your device backup. To
work on a folder from Files or iCloud Drive, use New project > Open a
folder; to move a project elsewhere, use Export as .zip.
